ربط العناصر بلون الموقع + تناسق أيقونات شريط الخاص
==================================================
الملفات (مساراتها نسبة لمجلد chat):
public/bars-site-color.js - قواعد لون الموقع للعناصر دي:
   1) رسائل الانضمام والتنقلات (شارة اسم الغرفة .roomh) - الوضعين البني والكحلي
   2) نافذة الإعدادات الافتراضية: الهيدر + زر اسم المستخدم + القوائم المنسدلة
   3) زر "عودة" داخل المميزات والإضافات والصفحات اللي بتتفتح منها
   4) أيقونات (أزرار) شريط الكتابة في الغرفة فقط - خلفية الشريط نفسها ما اتغيرتش
public/pm-footer-fix.css  - جديد: أيقونات شريط الكتابة في نافذة الخاص بمقاس موحّد (أزرار 30px وأيقونات 15px وإيموجي 30px وخانة الكتابة 30px)
public/index.ejs          - تحميل pm-footer-fix.css?1 + رقم النسخة bars-site-color.js?4

للرجوع: احذف سطر pm-footer-fix.css من index.ejs.
بعد النسخ: pm2 restart server ثم Ctrl+Shift+R
