Nopta.1.0 - تحصين زر التفعيل/الإيقاف وزر البنر الافتراضي (3 ملفات، انسخهم فوق نفس المسارات)

server.js            : أمر SEND_ADMIN_NOPTA بيرد دايمًا (نجاح / فشل كتابة في uploads / ماعندكش صلاحية) بدل الصمت
public/admin.js      : المفتاح بيستنى رد السيرفر (4 ثواني) وبيرجع لحالته الحقيقية مع رسالة سبب واضحة لو مفيش رد،
                       وزر "البنر الافتراضي" بقى يقرا رد السيرفر (قبل كده كان يعرض ✅ حتى لو السيرفر رفض)
public/admin.html    : رقم نسخة admin.js اتغيّر (?58n3 و ?x12n3) عشان المتصفح يحمّل الجديد

بعد النسخ:
1) pm2 restart server        (لازم - تعديل server.js)
2) افتح لوحة التحكم و Ctrl+Shift+R
3) جرّب المفتاح من تبويب الإضافات - لو في مشكلة هتظهر تحت المفتاح رسالة بالسبب بالظبط
4) بعد التشغيل/الإيقاف افتح الشات و Ctrl+Shift+R
