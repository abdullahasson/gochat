تعديل شكل البروفايل + إصلاح السكرول
====================================
الملفات (مساراتها نسبة لمجلد chat):
public/x2.js              - إصلاح: بعد زر "تنبيه" أو "تبليغ" وقفل النافذة الصغيرة، سكرول البروفايل كان بيقف (bootstrap بيشيل modal-open من الـ body والبروفايل لسه مفتوح). دلوقتي الكلاس بيرجع تلقائي، والنافذة الصغيرة بتتمسح من الصفحة بعد القفل.
public/level-badges.css   - ألوان الأزرار والأيقونات زي الصورة + الجزء السفلي من الأدوات الإدارية (الزخرفة/الايكات/النقاط/المجموعة/الغرفة) بلون الموقع
public/level-badges.js    - بيقرأ لون الموقع الحالي (من .label-primary) ويحطه في المتغير --pt-site لنافذة البروفايل عند كل فتح
public/users-style.js     - شلت اللون الذهبي المفروض على أيقونات البروفايل
public/index.ejs          - أيقونة اسكات / اسكات الحائط بقت ⊘ (fa-ban) بدل 🔇 + رفع أرقام النسخ (x2.js?79 / level-badges.css?5 / level-badges.js?4 / users-style.js?10)

بعد النسخ: pm2 restart server ثم Ctrl+Shift+R

ألوان الأزرار: محادثة/تنبيه/كشف النكات/تبليغ = أسود، الايكات = أحمر، هدية = أزرق، الصورة = maroon، البنر = pink، طرد من الغرفة = بنفسجي، طرد/باند/اسكات/اسكات الحائط = crimson، تجاهل = أحمر.
أي زر ليه لون inline في الـ HTML ومش في القايمة دي بيحتفظ بلونه.

--- إضافة: حذف الغلاف / الإطار / بنر الحالة ---
server.js                - أوامر جديدة delcover / delatar / delback (جنب delpic): بتتحقق من صلاحية "حذف صورة" (delpic) ومن رتبة العضو، وتفضّي الحقل (cover / atar / back) في الذاكرة وقاعدة البيانات وتبعت تحديث للمتصلين وإشعار للعضو وتسجل في السجل
public/x2.js             - ظهور الأزرار التلاتة مع زر حذف الصورة بنفس الشرط وإرسال الأوامر
public/index.ejs         - الأزرار: الغلاف (غلاف البروفايل) / الإطار (إطار الصورة في القايمة) / بنر الحالة (خلفية كارت العضو في المتصلين)
public/level-badges.css  - لونها أزرق غامق زي الصورة وترتيبها مع أزرار الأدمن
بعد النسخ: pm2 restart server ثم Ctrl+Shift+R
