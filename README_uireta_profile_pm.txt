Uireta.1.0 - تحديث: البروفايل + نافذة الخاص + شريط المقاعد
(انسخ الملفين فوق نفس المسارات داخل مجلد public)

public/uireta.css
public/index.ejs      (رقم نسخة uireta.css بس: ?12 -> ?13)

بعد النسخ: pm2 restart server ثم Ctrl+Shift+R (ولو فيه Cloudflare اعمل Purge Cache).

اللي اتعدّل (كله شغّال بس لما Uireta.1.0 يكون مفعّل):
1) البروفايل (#upro): الغلاف والصورة والاسم والليفلات والنقاط والعلم واسم الغرفة رجعوا لنفس تموضع الوضع الافتراضي بالظبط
   (السبب كان direction:rtl على الحاوية بيعكس الليفلات والعلم والغرفة + الجزء العلوي كان بيتعامل كبلوك واحد).
   الشكل بس اتغيّر لأخضر/ذهبي: شريحة النقاط ذهبي، زر الغرفة أخضر بحدود ذهبية، العلم والدولة بالأخضر، ليفلات بظل ذهبي، خلفية بيضا.
2) نافذة الخاص: هيدر أخضر بخط ذهبي (اسم العضو في كبسولة بيضا + زر البروفايل ذهبي + تكبير/تصغير دواير)،
   رسايل كروت مدوّرة، وشريط الكتابة أخضر بخانة بيضا مدوّرة وأزرار دواير والإرسال ذهبي (زي شريط الغرفة).
3) شريط المقاعد الصوتية: كان z-index:60 فبيعلى على لوحة النوافذ (#dpnl = 30) وبيخفي النوافذ اللي بتتفتح من الشريط السفلي.
   دلوقتي المقاعد z-index:auto، وقايمة خيارات المقعد 29 (لسه فوق شريط الأغنية وتحت النوافذ)، ولوحة النوافذ 40.
