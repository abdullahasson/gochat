إصلاح بنر اللوجين + زرّا الحماية
=================================
الملفات (مساراتها نسبة لمجلد chat):
server.js          - (1) إصلاح رفع بنر اللوجين: بقى بيستخدم sharp بدل Jimp القديم (كان بيرفض صور webp وغيرها)، ورفع مستقل مفيهوش تعليق، ويقبل أي صورة لحد 25 ميجا وبيقصها 1080x487
                     (2) أعلام الحماية لكل دومين + أوامر SEND_ADMIN_PROTECT_COPY / SEND_ADMIN_PROTECT_DEV + تمرير الحالة للصفحة + protect.js بدون كاش
public/protect.js  - جديد: سكريبت الحماية (بيتحمّل بس لو أي زر مفعّل)
public/index.ejs   - سطر واحد في الـ head لتحميل protect.js لو الحماية مفعّلة
public/admin.js    - دوال وحالة الزرّين + تعديل بسيط في قراءة رد رفع البنر
public/admin.html  - زرّا "حماية من النسخ وتحميل الصور" و"حماية من الكونسول F12" تحت زر البنر (تبويب الإضافات)

بعد النسخ: pm2 restart server ثم Ctrl+Shift+R
الاستخدام: لوحة التحكم > الإضافات > اضغط الزر (تفعيل)، اضغطه تاني = إلغاء. بعد التفعيل حدّث صفحة الشات.

ملاحظات:
- حماية النسخ: بتمنع تحديد النص والنسخ والقص وكليك يمين والسحب وحفظ/طباعة الصفحة (Ctrl+S/P/U) وسحب الصور، وخانات الكتابة بتفضل شغّالة عادي (كتابة + لصق).
- حماية الكونسول: بتمنع F12 وCtrl+Shift+I/J/C/K وCtrl+U، وبتكشف فتحها (حجم النافذة + debugger + فحص الكونسول) وتقفل الصفحة برسالة. لوحة التحكم نفسها (/cp) مش متأثرة.
- أي حماية من ناحية المتصفح بتصدّ الاستخدام العادي بس، مش حماية مطلقة (سكرين شوت أو أدوات خارجية أو تعطيل الجافاسكربت بيتخطّوها).

--- تصحيح الكاش ---
admin.html: أرقام نسخة admin.js / admin-ui.js اتغيّرت (v=20261010a) علشان المتصفح يسيب النسخة القديمة المخزنة سنة كاملة.
server.js : admin.js و admin-ui.js و admin-ui.css بقوا بدون كاش (زي protect.js) فأي تعديل مستقبلي يظهر فوراً.
مهم: لازم pm2 restart server (server.js اتعدّل)، وبعدها Ctrl+Shift+R في لوحة التحكم وفي صفحة الشات.
وزر "تغيير صفحة اللوجين" لازم يكون مفعّل علشان البنر يظهر.
