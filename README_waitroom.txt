غرفة الانتظار
الملفات (انسخها فوق نفس المسارات في مجلد chat):
waitroom.js (جديد) - server.js - config.js - powers.js
public/waitroom-admin.js (جديد) - public/admin.html - public/admin.js - public/admin-ui.js
بعد النسخ: pm2 restart server ثم Ctrl+Shift+R

الاستخدام: لوحة التحكم > غرفة الانتظار. الإعدادات بتتحفظ في uploads/waitroom.json.
الصلاحية: خانة "غرفة الانتظار" في تعديل الصلاحيات (صاحب "إداره الموقع" بيشوفها تلقائي).
التفعيل بينشئ غرفة ثابتة "غرفة الانتظار"، والإيقاف بينقل المنتظرين للعام ويحذفها.
