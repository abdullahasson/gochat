تغيير الشريط العلوي والسفلي
==========================
الملفات (مساراتها نسبة لمجلد chat):
server.js              - حفظ حالة الزر لكل دومين (ملف uploads/barstyle_<الدومين>.txt) + تمرير newbars للصفحة
public/bars-style.js   - جديد: شكل الشريط العلوي (السماعة + المايكات) والسفلي (6 أيقونات) ونقل الجرس
public/admin.js        - حالة الزر + دالة toggleBarsStyle
public/admin.html      - زر "تغيير الشريط العلوي والسفلي" تحت زر تغيير صفحة اللوجين (تبويب الإضافات)
public/index.ejs       - تحميل bars-style.js (?2) بس لو الزر مفعّل

بعد النسخ: pm2 restart server ثم Ctrl+Shift+R
الاستخدام: لوحة التحكم > الإضافات > اضغط الزر (تفعيل). اضغطه تاني = الرجوع للقديم وأيقونة الإشعارات ترجع مكانها في الضبط.

--- إضافة: قايمة المتواجدين بالشكل الجديد ---
public/users-style.js  - جديد: هيدر أسود + شريط القصص (دوائر بإطار ملوّن + زر أرشيفي) + شريط "المتواجدون في الغرفة" + كروت الأعضاء (صورة مربعة وشريط حالة ونص الحالة والعلم)
server.js              - تعديل سطر واحد: إضافة users-style.js لقائمة no-cache
public/index.ejs       - تحميل users-style.js?1 مع bars-style.js (بس لو الزر مفعّل)
public/admin.js        - تحديث نص حالة الزر فقط
نفس الزر (لوحة التحكم > الإضافات > تغيير الشريط العلوي والسفلي) بيشغّل القايمة الجديدة، وإلغاؤه يرجّعها للشكل القديم.
