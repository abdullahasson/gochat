Uireta.1.0 - تحديث: قايمة المتصلين + الإطار المتحرك + نافذة الإعدادات
انسخ الملفات فوق نفس المسارات (مجلد public):
  public/uireta.css
  public/uireta.js
  public/index.ejs   (رقم النسخة بس: uireta.css?12 و uireta.js?12)
بعد النسخ: pm2 restart server ثم Ctrl+Shift+R (ولو فيه Cloudflare اعمل Purge Cache).

اللي اتعدّل:
1) كارت قايمة المتصلين جوه الشات بقى بنفس اتجاه الشكل الافتراضي: الصورة شمال، والعلم والرقم والبادج يمين، والاسم والرسالة محاذاة شمال.
2) الإطار المتحرك (atar): بيظهر لما العضو يكون ifedit وعنده إطار. اتثبّت مكانه ومقاسه بالـ CSS، واتشال المربع الرمادي اللي كان حواليه.
   وكروت اللوجين من برا بقت بترسم الإطار كمان (كانت مش بترسمه خالص).
3) الشريط العلوي لقايمة المتصلين ونافذة الإعدادات: هيدر أخضر بخط ذهبي وزر إغلاق ذهبي.
4) نافذة الإعدادات: ملصقات خضرا، حقول زي حقول اللوجين، أزرار بيضا مدوّرة، الألعاب ذهبي، الإضافات أخضر، الخروج أحمر.
كله شغّال بس لما Uireta.1.0 يكون مفعّل (body.uireta-on).

تحديث 3 - الألوان رجعت (أخضر + ذهبي) بشكل حديث وخفيف:
5) الشريط العلوي (المايكات): أخضر غامق بخط ذهبي تحته، مقاعد دواير بيضا بحدود ذهبية، والمتكلم بيتوهّج ذهبي.
6) الشريط السفلي: أخضر غامق بخط ذهبي فوقه، أيقونات ذهبية فوق والاسم تحتها، وعدّادات ذهبية. (الأيقونات مصلّحة ومتناسقة.)
7) شريط الكتابة: أخضر، خانة بيضا مدوّرة، أزرار دواير بنفس المقاس، وزر الإرسال ذهبي.
8) رسايل الغرفة: كروت بحواف مدوّرة وظل ناعم.
9) محتويات نافذة الإعدادات: كروت بيضا على خلفية فاتحة، عناوين خضرا بعلامة ذهبية، أيقونات في مربعات مدوّرة، زر حفظ أخضر، الألعاب ذهبي، الإضافات أخضر، وحذف/خروج بالأحمر.

تحديث 4:
10) الإعدادات (عربي RTL حديث): هيرو للصورة الشخصية (بانر أخضر + صورة دايرية بإطار ذهبي + "تغير الصوره")، "حذف الصوره" رابط صغير، كروت للحقول والألوان، صفوف بأيقونة يمين وسهم يسار، وزر الحفظ أخضر متدرّج.
11) الحائط: هيدر أخضر بخط ذهبي، زر "مبدع الحائط" ذهبي، تبويبات الريشة/الحائط كبسولات، بحث يوتيوب كبسولة بيضا، كروت المنشورات مدوّرة بأزرار (قلب/رد/حذف) كبسولات ملوّنة، وشريط الكتابة أخضر زي شريط الغرفة.

تحديث 5 - الحائط (كارت المنشور الجديد):
12) كارت أبيض بحواف مدوّرة 20px وظل ناعم، أفاتار دايري بإطار ذهبي، اسم العضو في كبسولة، الوقت كبسولة صغيرة فوق، النص بخط Tajawal ومسافات مريحة،
    وشريط الأزرار (قلب / رد / حذف) تحت خط خفيف وبكبسولات ملوّنة (بيختفي لو مفيش أزرار ظاهرة). مقاطع يوتيوب بصورة مصغّرة مدوّرة وزر تشغيل، والصور داخل المنشور مدوّرة.
    خلفية الحائط بتدرّج أخضر فاتح. (بيحافظ على ألوان الاسم والإطارات اللي العضو مخصصها.)

تحديث 6: إصلاح أيقونات أزرار منشورات الحائط (قلب/رد/حذف) - كانت بتتخبّى لما الزر يكون عليه كلاس hid ومظهَر بـ display جوه الـ style. دلوقتي بتظهر بنفس شروط الإظهار الأصلية.

تحديث 7 - نافذة التعليقات (#cooment): هيدر أخضر بخط ذهبي وزر إغلاق ذهبي، بطاقة المنشور الأصلي فوق، التعليقات فقاعات بيضا بصورة دايرية بإطار ذهبي ووقت كبسولة، وشريط كتابة أخضر بزر إرسال ذهبي. النافذة بقت متوسّطة وبعرض مناسب للموبايل.

تحديث 8:
13) قايمة المتصلين: العلم فوق، الهاشتاج في النص، وبادج VIP / مشرف / مدير تحت الهاشتاج (عمود واحد متناسق).
14) خيارات المقعد (سحب المايك / إيقاف الصوت / فتح البروفايل / تشغيل موسيقى): بقت فوق شريط الأغنية بالكامل بدل ما يغطيها (رفع z-index للمقاعد + overflow ظاهر)، وبتصميم أخضر بأزرار كبسولات.
15) البروفايل (#upro) والأدوات الإدارية: هيدر أخضر/ذهبي، شبكة أزرار خفيفة بألوان ناعمة (كل زر بلون أيقونته)، محادثة خاصة أخضر، هدية ذهبي، وصناديق التحكم (الزخرفة/الايكات/النقاط/المجموعة/الغرفة) في كروت بيضا بحقول وأزرار مدوّرة.
