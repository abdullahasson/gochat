شكل الإعدادات الجديد (مربوط بزر تغيير الشريط العلوي والسفلي)
=============================================================
الملفات (مساراتها نسبة لمجلد chat):
public/settings-style.js - جديد: شكل لوحة الإعدادات زي الصورة (هيدر أسود + زر إغلاق أحمر، ملصقات سودا، مربعات الألوان، حفظ/X، أزرار طويلة ملونة)
public/index.ejs         - تحميل settings-style.js بس لو الزر مفعّل (جنب bars-style.js)
public/admin.js          - نصوص حالة الزر بقت "الشريط + الإعدادات"
server.js                - سطر واحد: settings-style.js بدون كاش (زي bars-style.js)

بعد النسخ: pm2 restart server ثم Ctrl+Shift+R
الاستخدام: لوحة التحكم > الإضافات > "تغيير الشريط العلوي والسفلي" (تفعيل) = الشريط + الإعدادات الجديدة. اضغطه تاني = الرجوع للافتراضي.

ملاحظات:
- الملف بيحرّك العناصر الأصلية مش بينسخها، فحفظ البروفايل والألوان والإشعارات والخروج وكل الدوال القديمة شغّالة زي ما هي.
- عناصر موجودة قبل كده وفضلت بنفس الشكل: حدود الصورة، السيرفر الصوتي، الألعاب، إرسال إعلان، إدارة الغرفة، لوحة التحكم (بتظهر حسب الصلاحية زي الأول).
- "استكشف" = زر الاضافات والميزات القديم (بيفتح نفس الصفحة).
- "لون التصميم الأصلي" = يلغي الوضع الليلي ويرجّع حجم الخط 100% على المتصفح ده بس.
- "تفريغ بيانات الموقع" = مسح تخزين المتصفح (دخول محفوظ + قائمة التجاهل) وإعادة تحميل، بعد تأكيد.
- "المستخدمون المتجاهلين" = نافذة فيها القايمة (المحفوظة في المتصفح) مع زر إلغاء التجاهل.

تحديث: هيدر لوحة الإعدادات بقى بيتلوّن فوراً (بـ :has) بدون رعشة، وكل الأحجام اتصغّرت ~18% (المتغيّر K في settings-style.js، قيمته 0.82).
