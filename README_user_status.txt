زر "حالتي الآن" في الإعدادات (تحت زر الألعاب) + ظهور الحالة في قايمة المتصلين
===========================================================================
الملفات (مساراتها نسبة لمجلد chat):
public/user-status.js - جديد: الزر + نافذة الاختيار (نفس شكل وألوان الكود المرجعي) + شارة الحالة في صف العضو
public/index.ejs      - سطر واحد: تحميل user-status.js?1 جنب settings-default.js
server.js             - أمر جديد SEND_EVENT_EMIT_MYSTATUS (رقم 0..5) بيتخزّن في الحقل ust ويتبث للكل (u^)

الحالات والأيقونات:
0 بدون حالة (رمادي) - 1 متاح (أخضر، صح) - 2 مشغول (أحمر، ناقص) - 3 صلاة (ذهبي، مسجد)
4 مكالمة (أزرق، تليفون) - 5 بالخارج (رمادي فاتح، خروج)

الشغل:
- الزر بيظهر تحت زر الألعاب في التصميم الافتراضي وفي Nopta.1.0.
- الحالة بتتحفظ في المتصفح (localStorage "myStatus") وبتتبعت تاني تلقائي بعد أي دخول/إعادة اتصال.
- الشارة (أيقونة + اسم الحالة) بتظهر جنب اسم العضو في قايمة المتصلين وتبويب الخاص، و"بدون حالة" ومتخفّي = من غير شارة.
- user-status.js بيغلّف دالة updateu بس من غير ما يغيّر فيها، فكل الكود القديم شغّال زي ما هو.

بعد النسخ: pm2 restart server ثم Ctrl+Shift+R   (لازم restart عشان server.js اتعدّل)

لو index.ejs عندك متعدّل ومش عايز تستبدله، ضيف السطر ده بعد سطر settings-default.js:
  <script defer src="user-status.js?1"></script>
لو server.js عندك متعدّل: ضيف الفرع ده قبل else if (data["cmd"] == "SEND_EVENT_EMIT_BUSY") (موجود جاهز في الملف المرفق).
للإلغاء: احذف سطر user-status.js من index.ejs.

تحديث (اختفاء الشارة بعد ثواني):
- غلاف updateu بقى بيحافظ على علامات الأغلفة التانية (__uh / __nf / __pc) عشان ما يلخبطش uhide / nfont / profile-cover.
- حالتي أنا بتتقرا دايماً من المتصفح فمبتختفيش، وحالة غيري بتتحفظ في كاش لو كائن العضو اتبدّل بنسخة من غير الحقل ust (u+ / ulist / إعادة اتصال).
- فحص خفيف كل ثانية للصفوف الظاهرة (~40 صف) بيرجّع الشارة لو اتمسحت.

تحديث (الأيقونات + اختفاء الشارة):
- الأيقونات كلها بقت SVG (من غير خط FontAwesome): السبب إن قاعدة "#us-modal *" و"#us-wrap *" كانت بتغيّر الخط لـ Tajawal بـ !important فبتخفي أيقونات FontAwesome. الشكل بقى زي الكود المرجعي (دايرة صح / دايرة ناقص / مسجد / سماعة / شخص ماشي بسهم).
- الشارة: مراقب DOM فوري + فحص كل 0.7 ثانية + إعادة تغليف updateu لو حد استبدلها + شارة صفّي ما بتتخفاش بعلامة التخفّي.
- تشخيص: لو لسه الشارة بتختفي افتح الكونسول واكتب usDebug() وابعتلي الناتج.
- الملفات: public/user-status.js و public/index.ejs (user-status.js?3)  — بعد النسخ: Ctrl+Shift+R (من غير restart).
